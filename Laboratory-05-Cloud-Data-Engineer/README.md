# Laboratory 05 - Cloud Data Engineer

## Mission Overview

The mission of this laboratory is to deploy and configure MinIO as an object storage server using Docker. The laboratory focuses on understanding cloud storage concepts, deploying a storage service, creating an object storage bucket, and documenting the deployment process.

## Objectives

- Understand the three primary types of cloud storage: Block, File, and Object Storage.
- Deploy a MinIO storage server using Docker.
- Configure MinIO using environment variables.
- Access and navigate the MinIO web console.
- Create and manage an object storage bucket.
- Document the technical steps used during deployment.
- Reflect on the advantages of object storage for large-scale data.

## Tools Used

- Docker
- MinIO
- GitHub
- Linux Command Line
- Web Browser
- Markdown

## Skills Learned

- Understanding different types of cloud storage.
- Deploying services using Docker containers.
- Using environment variables to configure applications.
- Navigating the Linux command line.
- Creating and managing MinIO buckets.
- Working with object storage concepts.
- Writing technical documentation using Markdown.
- Managing and organizing project files using GitHub.
