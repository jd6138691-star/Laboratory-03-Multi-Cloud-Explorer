## Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) was introduced in 2006 and has grown into one of the most widely used cloud computing platforms. It offers a variety of cloud and AI solutions that help businesses, organizations, governments, and developers create, manage, and improve their digital systems.

AWS helps customers avoid the need to maintain large amounts of physical hardware and infrastructure. Its services are used by startups, enterprises, non-profit organizations, and government agencies to improve their operations, develop applications, protect data, and support business growth.

## AWS Global Infrastructure

AWS operates a large worldwide cloud infrastructure consisting of Geographic Regions and Availability Zones. These locations allow organizations to run their applications closer to their customers while improving system performance, reliability, and availability.

AWS currently operates 124 Availability Zones across 39 Geographic Regions, with additional regions and Availability Zones planned for the future.

## Cloud Management Console

The AWS Management Console is an online interface that allows users to access and manage AWS services. Through the console, users can create, configure, monitor, and control their cloud resources from one central location.

The console provides access to services such as Amazon EC2, Amazon S3, Amazon RDS, and Amazon VPC, making cloud resource management easier for users.

## Four (4) Core Services

1. **Amazon EC2** – Provides virtual servers that can be used to run applications and workloads.
2. **Amazon S3** – Provides cloud storage for files, backups, documents, and other data.
3. **Amazon RDS** – Provides managed relational database services.
4. **Amazon VPC** – Provides a private and controlled networking environment within AWS.

## Three (3) Advantages

1. **Simple Resource Management:** The AWS Management Console provides a graphical interface that makes it easier to create and manage cloud resources.

2. **Centralized Administration:** Users can access and manage services, permissions, billing information, and monitoring tools through one platform.

3. **Built-in CloudShell:** AWS CloudShell provides a browser-based terminal where users can execute commands and scripts without needing to install a separate command-line environment.

## Typical Enterprise Use Cases

**Application Development and Testing:** Businesses can use AWS to create development and testing environments quickly without purchasing additional physical servers.

**Data Storage and Backup:** Organizations can use services such as Amazon S3 to store important business files, backups, and other digital information.

**Websites and Business Applications:** Enterprises can use Amazon EC2, Amazon RDS, and Amazon VPC to host websites, applications, databases, and other business systems.

**Cost and Financial Management:** Companies can use AWS billing and cost management tools to monitor cloud usage, track expenses, and control their cloud budgets.
