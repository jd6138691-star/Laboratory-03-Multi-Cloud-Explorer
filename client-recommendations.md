# Checkpoint 4 – Cloud Platform Recommendation Challenge

CloudNova Technologies has received requests from four clients. Each client has different requirements, so the most appropriate cloud platform is selected based on scalability, compatibility, performance, availability, and business needs.

## Client A – Startup Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the startup because it provides flexible and scalable cloud services. The company can start with a small amount of computing resources and increase them as the application gains more users. AWS also provides many services that can help the startup develop and operate its mobile application without purchasing physical servers. This makes AWS suitable for a company with a limited budget and plans for rapid growth.

### Recommended Services

- **Amazon EC2** – Provides virtual servers for running the application's backend.
- **Amazon S3** – Stores application files, images, videos, and other data.
- **Amazon RDS** – Provides a managed relational database for application data.
- **Amazon CloudFront** – Delivers application content quickly to users.

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is recommended for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making the migration process easier. The university can connect its existing infrastructure to Azure and gradually move selected services to the cloud. This allows the university to continue using familiar Microsoft technologies while gaining the benefits of cloud computing.

### Recommended Services

- **Azure Virtual Machines** – Runs Windows Server workloads in the cloud.
- **Microsoft Entra ID** – Provides identity and access management.
- **Azure Blob Storage** – Stores documents, backups, and other university files.
- **Azure Virtual Network** – Connects and secures cloud resources.

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform is recommended because the company develops Artificial Intelligence and Machine Learning applications that require high-performance computing. GCP provides powerful computing resources and specialized AI and machine learning services. The company can use these services to develop, train, and deploy machine learning models. GCP also provides managed Kubernetes services that can support scalable AI applications.

### Recommended Services

- **Google Compute Engine** – Provides scalable virtual machines for high-performance computing.
- **Vertex AI** – Provides tools for developing, training, and deploying machine learning models.
- **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized applications.
- **Google Cloud Storage** – Stores datasets, research files, and machine learning models.

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Amazon Web Services (AWS)

AWS is recommended for the global e-commerce company because it provides highly available and scalable infrastructure. The company can use multiple AWS Regions and Availability Zones to improve availability for customers around the world. AWS Auto Scaling can automatically increase or decrease computing resources based on customer traffic. Load balancing and content delivery services can also help maintain fast and reliable performance during periods of high demand.
