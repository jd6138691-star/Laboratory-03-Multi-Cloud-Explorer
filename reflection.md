
## Checkpoint 8 – Mission Reflection
Mission Reflection
Among AWS, Microsoft Azure, and Google Cloud Platform, the cloud platform that impressed me the most is Amazon Web Services (AWS). I was impressed by its wide range of services, scalability, and global infrastructure. AWS can support different types of organizations, from small startups to large enterprises, and provides services for computing, storage, databases, networking, security, and application development.

AWS, Azure, and GCP have many similarities. All three cloud platforms provide computing, storage, databases, networking, security, identity management, and scalable cloud resources. They also allow organizations to access cloud services through the internet without needing to maintain all physical infrastructure themselves. Each provider also offers virtual machines, object storage, managed databases, and Kubernetes services.

Business requirements are important when selecting a cloud platform because every organization has different needs. Factors such as budget, existing technologies, security, performance, scalability, availability, and application requirements must be considered. For example, Azure is a good choice for organizations that already use Microsoft technologies, while GCP is a strong option for Artificial Intelligence, Machine Learning, and Kubernetes workloads.

Acting as a Cloud Solutions Consultant taught me that there is no single cloud provider that is best for every organization. I learned how to analyze a client's requirements and match those requirements with the appropriate cloud platform and services. I also learned that cloud decisions should be based on business needs rather than simply choosing a popular provider.

My GitHub Cloud Computing Portfolio has improved significantly after completing this mission. It now contains cloud research, platform comparisons, service mappings, client recommendations, a decision matrix, Linux server investigation, and a mission reflection. This activity helped me improve my technical knowledge, documentation skills, problem-solving abilities, and understanding of how cloud computing can be applied to real-world organizations.
